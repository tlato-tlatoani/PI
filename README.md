# ⚽ MexScan

MexScan es una aplicación web interactiva que utiliza Realidad Aumentada para ofrecer una experiencia única alrededor del fútbol y el Mundial de la FIFA 2026 🌎🏆  
[👉 Pruébalo](https://pi-green-seven.vercel.app/)
## ✨ Con MexScan puedes:

### 📷 Escanear escudos de selecciones
*Aprende información relevante de cada equipo de forma interactiva.*
### 🎥 Explorar contenido multimedia
*Visualiza, filtra y descarga videos relacionados al mundial.*
### 📊 Consultar estadísticas
*Revisa datos de las selecciones que jugarán en Monterrey en el Mundial 2026.*
## 🛠️ Tecnologías utilizadas
- 🌐 HTML, CSS, JavaScript
- 🧠 Realidad Aumentada (MindAR)
